# 合金系列与强化机制

5xxx 系列属于非热处理强化合金，主要依靠镁的固溶强化与加工硬化；焊接会使加工硬化状态附近的热影响区软化。6xxx 系列属于热处理强化合金，熔焊热循环会重新分布强化相，使热影响区局部降强。因此，6061-T6 或 6063-T6 的焊态接头不能直接沿用母材 T6 强度。

5xxx 系列通常具有较好的熔焊性。高镁合金如 5083 不应随意选用 4xxx 填丝，因为可能在熔合边界形成不利组织并降低延性、增加裂纹敏感性。6061 可把 4043 或 5356 作为候选，但要根据裂纹敏感性、接头强度、腐蚀、服役温度和阳极氧化外观综合选择。

# 常见缺陷控制

铝合金熔焊常见风险包括气孔、裂纹和不良焊缝成形。控制水分与油污、焊前脱脂、去除氧化膜、保持焊丝干燥和保护气系统严密，是降低气孔和夹杂风险的基础。清理工具应为铝专用，避免钢铁污染。
