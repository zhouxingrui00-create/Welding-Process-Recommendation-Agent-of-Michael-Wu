# 不能跨条件套用

Miller 的典型表是铝合金角焊缝起始参数，按名义板厚和焊接位置区分。种子数据库只转录了少量用于自动化测试的行，并保留原始英制单位说明。对接焊缝、不同散热条件、不同设备波形或超出厚度窗口时，系统不输出这些数值。

表下注释特别提醒：过高温度或长时间预热会降低焊缝强度，热处理状态母材尤其敏感。表中焊道数量和填充材料消耗仅针对单侧焊接。因此，即使数据库命中厂商行，也只能作为试焊起点，不能直接成为 WPS。
