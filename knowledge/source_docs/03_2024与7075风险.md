# 高风险提示

2024 是 Al-Cu-Mg 系热处理强化合金，7075 是 Al-Zn-Mg-Cu 系热处理强化合金。ESAB 将二者列为通常不适合电弧焊的一小组高强铝合金。主要问题不仅是焊接时的热裂纹，还包括焊后在拉应力与腐蚀环境共同作用下发生的延迟应力腐蚀开裂；刚焊完外观正常并不能证明服役安全。

安全关键或承载构件不得直接采用通用 TIG/MIG 参数修复。应先由材料和焊接专业人员确认牌号、服役载荷、环境和失效后果，并优先评估机械连接、重新设计或经专项评定的固相连接方案。
