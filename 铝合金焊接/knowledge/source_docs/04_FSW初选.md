# 方法优势与约束

FSW 是固相连接过程，可用于一些因液化和凝固裂纹而不宜熔焊的热处理强化铝合金。它因此适合作为 2024、7075 等材料的优先评估方向，而不是把普通 TIG/MIG 参数强行套用到高风险合金。

FSW 仍然不是“免评定”过程。工具肩部与搅拌针几何、转速、行走速度、轴向力、下压量、装夹刚度和背衬都会影响缺陷与性能。种子库没有这些精确窗口；必须针对设备、工具、板厚、接头和状态做试验设计及接头性能验证。常规 FSW 对接头可达性、平焊位置和刚性装夹也有明确要求。
