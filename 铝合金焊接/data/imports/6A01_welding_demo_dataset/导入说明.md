# 6A01_welding_demo_dataset：JSON 转换草稿

本批仅依据用户指定的 `6A01_welding_demo_dataset.xlsx` 转换。数值来自 `6A01_demo_dataset!A2:U8`，字段名来自第 1 行；README 工作表作为来源说明原样保留，不作为额外实验。

## 输出内容

| 文件 | 数量 | 含义 |
| --- | ---: | --- |
| `materials/6A01/welding_cases.json` | 7 | 原表每行对应一个工艺摘要记录，保留不同 data_type |
| `materials/6A01/properties.json` | 3 | ID 1、2、3 的抗拉/疲劳性能摘录，与案例通过 case_id 关联 |
| `materials/6A01/literature.json` | 6 | 按 DOI 或专利号去重后的来源：5 篇论文、1 项专利 |
| `raw_records.json` | 2 个工作表 | 原始单元格快照，包含空值、说明、原始列名和文件哈希 |
| `source_checks.json` | 6 | 公开来源标识核对记录，明确核对范围 |
| `source/6A01_welding_demo_dataset.xlsx` | 1 | 原始工作簿副本，内容未修改 |

这批 JSON 位于 `data/imports/`，用于检查映射。正式材料库 `data/materials/6A01/`、已有模块、主 README 和其他材料保持原样；当前页面不会自动读取本批草稿。

## 行与来源关联

| Excel ID | 工艺 | 记录性质 | 对应来源 |
| --- | --- | --- | --- |
| 1 | MIG | 论文报告的测量摘要 | 10.1016/j.msea.2018.12.080 |
| 2 | Laser-MIG hybrid | 论文报告的测量摘要 | 10.11896/cldb.21110142 |
| 3 | Laser-CMT hybrid welding-brazing | 论文报告的最优条件摘要 | 10.3390/ma12223651 |
| 4 | Fiber laser welding | 数据集实验设置，无单次性能/缺陷测量结果 | 10.3390/ma17133270 |
| 5 | Laser-MIG hybrid | 实测/模型验证混合标记，具体性质待图表核实 | 10.1016/j.ijthermalsci.2025.109785 |
| 6 | Laser-MIG hybrid | 同论文另一间隙条件，单独保留案例 | 同上，与 ID 5 共用 literature_id |

这里的 7 条是原表的工艺摘要，不等于 7 次已核实的独立实验；3 条性能摘录也不是额外的 3 次实验。需按 case_id 去重。数据集设置和专利实施例不应直接混入实测训练集。

## 主要字段映射

| Excel 列 | JSON 字段 |
| --- | --- |
| Alloy / Temper / Thickness_6A01_mm | alloy / temper / thickness_mm |
| Process | welding_method，完整保留原方法名，不归并成普通 MIG |
| Joint / Other material | joint.description，保留原始接头/对侧材料描述 |
| Filler / Filler_diameter_mm | welding_parameters.filler_material / wire_diameter |
| Laser_power_kW / Arc_current_A | welding_parameters.laser_power / arc_current |
| Wire_feed_m_min / Welding_speed_m_min | welding_parameters.wire_feed_speed / welding_speed |
| Gap_mm / Shielding_gas | welding_parameters.gap / shielding_gas |
| Tensile_strength_MPa / Fatigue_strength_MPa | mechanical_properties.tensile_strength / fatigue_strength |
| Weld_depth_mm | geometry_results.penetration_depth，属于几何结果 |
| Other_outcome / Notes | other_outcome / notes，原文完整保留 |
| Data_type | data_type，另用 record_kind 标记记录性质 |
| Source_DOI_or_URL | source.url；解析 DOI 或专利号，并生成 literature_id |

有明确列单位的数值拆成 value / unit，并附 source_cell。Excel 空白保持 null，不补 0。ID 5 的 Gap_mm=0 为真实记录值，保留为 0。

ID 7 的 3.0 m/min 位于 `Welding_speed_m_min`，因此明确映射到 welding_speed；焊丝直径的单位也明确来自 `Filler_diameter_mm`。这些判断直接依据新表列名，不沿用其他输入的推断。

`High-purity Ar, 20 L/min` 保留为保护气原文。说明列中的光斑、对侧厚度、热源间距、离焦量等内容完整保存在 notes，不从简写再推断额外条件。气孔减少是定性描述，porosity_fraction 仍为 null；数据集用途不转成已发生气孔的标签。断裂位置放在 fracture_information，不自动当作焊接缺陷。

## 来源与核实状态

DOI/URL 来自 Excel；文献标题及部分作者、年份来自本次公开来源匹配，具体出处逐条保存在 `source_checks.json` 和 `metadata_provenance`。没有取得的作者、年份和原文页码保持 null。数值本身保持 Excel 原值，没有通过网页补齐空白实验参数。

本次核对定位了期刊/论文存档的书目信息和专利实施例，但未完成所有数值、实验条件和图表的全文审核。因此全部案例的 eligible_for_recommendation 和 eligible_for_training 均为 false。核对专利实施例不代表它已成为同行评议论文、标准或已批准工艺。

现有 MaterialManager 不自动执行 verification 字段的准入过滤。草稿通过独立目录与正式库隔离；不要仅因添加了这些标记，就把未审核数据直接复制进正式推荐路径。
